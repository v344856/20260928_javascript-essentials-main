# JavaScript & TypeScript Essentials

**Course Outline**

---

## About This Course

- **Duration:** 5 days (Monday-Friday, 8:30 am-4:30 pm ET)
- **Delivery:** Instructor-led, with prepared code demos, hands-on activities, and reference documentation.
- **Audience:** Technical professionals and technical managers who develop or oversee web applications
  and need a solid foundation in JavaScript and TypeScript to improve productivity, code reliability, and
  team collaboration. Attendees already program: variables, functions, and loops are assumed.
- **Prerequisites:** Basic computer skills, along with experience in HTML and introductory CSS.
- **Platform:** Windows-first; terminal examples use PowerShell. Node.js (current Active LTS) and
  Visual Studio Code are used throughout.

### What You Will Learn

- Write clean, functional **JavaScript** for dynamic web pages.
- Apply **regular expression** patterns to validate user input securely.
- Parse, generate, and manipulate **JSON** data for seamless API integration.
- Control the **Document Object Model (DOM)** to create interactive user interfaces.
- Implement **asynchronous** operations using callbacks, promises, and async / await.
- Transition JavaScript code to **TypeScript**, adding static types for early error detection.
- Structure projects with **modular** JavaScript / TypeScript and manage dependencies.
- Debug effectively in browsers and Visual Studio Code, employing **linters and formatters** to enforce
  code standards.
