# 04. Conditionals

Surveys JavaScript's decision-making constructs in one file: a simple `if/else` (adult vs. minor), an `if/else if` chain that maps a score to a letter grade, a `switch` on the day of the week (including an intentional fall-through for Saturday/Sunday), and a ternary expression choosing a price.

## Run

```bash
node index.js
```

This folder is its own project: run `npm install` once,
then `npm run lint` and `npm run format` use the ESLint and Prettier setup taught in
[Module 01 · Linters and Formatters](../../docs/Module-01-Getting-Started/03-linters-and-formatters.md).

## What it demonstrates

- `if` / `else` and `else if` chains for branching on comparisons.
- The `switch` statement with `break`, a `default` case, and deliberate case fall-through.
- The ternary operator (`condition ? a : b`) as a concise inline conditional.
